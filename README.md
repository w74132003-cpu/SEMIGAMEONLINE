# WaferRun 課堂版

老師開一個房間，學生用手機或電腦輸入 4 個字母的房號（或掃 QR code）加入，
全班在同一時間倒數 3、2、1、GO! 後開始玩《WaferRun》，結束後老師的畫面會顯示排行榜和頒獎台。

學生**不需要註冊、不需要帳號**，只要有瀏覽器。伺服器跑在老師的 GitHub Codespaces 上，不同網路、遠距上課都能玩。

---

## 一、第一次設定（只要做一次）

1. 登入 GitHub，建立一個新的儲存庫（Repository），可以選 **Private**。
2. 把這個資料夾裡的**所有檔案**上傳到儲存庫。
   - 用「拖曳」的方式上傳，**`public` 資料夾也要一起上傳**（不要用「選擇檔案」，那樣會漏掉資料夾）。
   - 上傳後，確認儲存庫裡看得到 `public` 資料夾，裡面有 `index.html`、`host.html`、`three.min.js`、`qrcode.js`。

## 二、上課當天

1. 在儲存庫頁面按綠色「**Code**」→「**Codespaces**」→「**Create codespace on main**」（已經建過的就直接點開它）。第一次約 1 分鐘。
2. 在下方的終端機輸入：

   ```
   bash codespace-start.sh
   ```

3. 終端機會印出**學生網址**和**老師頁面**。預設**不用密碼**，直接開「老師頁面」的網址即可。
   **別把老師頁面的網址貼給學生**，學生網址才是要給學生的。
4. 如果學生打不開：點下方「**連接埠**」（Ports）分頁，在 3000 那一列按右鍵 →「連接埠可見度」→ 選 **Public**。
5. 在老師頁面選「加入時間」和「遊戲時間」，按「**開房**」。
6. 把畫面投影出來，上面有**網址、房號和 QR code**，學生輸入或掃描即可。
7. 學生陸續加入會出現在名單上。時間到會自動開始，也可以按「**立即開始**」；想多等一下按「**多等 30 秒**」。
8. 開始後，學生畫面會依序砸出 **3、2、1、GO!**，GO! 的那一刻全班同時開始。老師畫面會即時顯示：
   - **廠房即時地圖**：每位學生是一個小圓點（顏色代表目前良率，金色外框＝已完成），機台右上角的數字是正在那一站的人數。人很多時不會顯示全部名字，只在發生事件時冒出名字；滑鼠移到圓點或點一下可以看名字，也可以在右上角輸入暱稱找人。
   - **即時動態**：摔晶圓、被課長唸、完成各站（完美或不佳）、地震警報、緊急插單等事件會即時出現；同一時間大量同學做同一件事，會合併成一行。
   - 下方仍有即時排行與每個人的進度。
9. 大家都完成（或遊戲時間到）後，按「**結束並公布結果**」。學生手機上會出現自己的名次，老師畫面出現頒獎台和完整成績。
10. 想留紀錄可按「**下載成績（CSV）**」，用 Excel 就能開。
11. 下課後到 https://github.com/codespaces 把這個 Codespace **停止或刪除**，以免耗用免費額度。

## 三、學生怎麼加入

- 手機或電腦的瀏覽器打開老師畫面上的網址，輸入房號和暱稱，按「加入房間」。或直接掃 QR code，房號會自動帶入。
- 加入後會看到等待畫面，老師開始後會有倒數 3、2、1、GO!。
- 遊戲開始後才來的人**不能**加入（需要老師開下一場）。
- 不小心斷線或重新整理：用**同一個暱稱**再加入一次就能回到房間
  （但遊戲進度會從頭開始，所以請盡量不要重新整理）。
- 遊戲中有淡淡的背景音樂，點右上角的喇叭（或首頁的「聲音」）可以關掉。
- 完成後可以按「🖼 看成績卡」，產生一張 9:16 的成績圖卡（含名次與分數），手機長按圖片即可存圖，電腦在圖片上按右鍵「另存圖片」。

## 四、怎麼算分數、排名

排名以**分數**高低為準：

> 分數 ＝ 良率 × 10 ＋ 節省的遊戲時間（每少 1 分鐘加 1.5，以 360 分鐘為基準）－ 摔晶圓每次 80 － 被課長罵每次 20

- 良率最重要，其次是用時短，摔晶圓與被罵會扣分。
- 同分時，用時短的排前面。
- 時間到時還沒跑完的同學，不計入名次。
- 想改公式：在 Codespace 左側檔案列表打開 `server.js`，找到 `calcScore` 那幾行修改，存檔後在終端機按 `Ctrl + C` 停止，再重新輸入 `bash codespace-start.sh`。

## 五、更新檔案

之後如果有新版檔案：
- 只換 `public/index.html`（學生頁面）：直接在 Codespace 裡覆蓋該檔，**不用重啟**，學生重新整理就生效。
- 換 `server.js`、`codespace-start.sh` 或 `public/host.html`：覆蓋後，終端機按 `Ctrl + C` 停止，再執行 `bash codespace-start.sh`；老師頁面也要重新整理。
- 如果是開了新的 Codespace，記得先把更新後的檔案提交（commit）並同步（sync）到 GitHub，新的 Codespace 才會有最新檔案。

## 六、常見問題

**打開學生網址卻看到「找不到頁面」或 404？**
- 先確認 3000 連接埠是 **Public**（見上面第二節第 4 點）。
- 如果之前的伺服器還在跑（終端機出現 `EADDRINUSE`），輸入 `pkill -f "node server.js"`，再重新執行 `bash codespace-start.sh`。
- 如果提示「檔案遺失：index.html」，代表 `public` 資料夾沒有上傳成功，請重新拖曳上傳。

**點老師網址卻出現學生的遊戲畫面？** 老師頁面的網址結尾是 `/host`，沒有 `/host` 的是學生網址。

**Codespace 會自己關機嗎？** 會。閒置一段時間後會自動關機（預設時間較短，可到 GitHub 右上頭像 → Settings → Codespaces 調整）。上課前先開好，上課中保持瀏覽器分頁開著。
房間資料只存在伺服器的記憶體裡，Codespace 關機或重啟後就消失，所以下課前記得先下載成績。

**免費額度夠用嗎？** GitHub 個人帳號每月有免費的 Codespaces 使用額度（基本機型約數十小時；實際額度請以 GitHub 的說明頁為準）。只在上課時開、下課就停止的話通常足夠。

**想加老師密碼？** 預設免密碼。想加密碼：GitHub 右上頭像 → Settings → Codespaces → Secrets，新增名為 `HOST_PASS` 的 secret，之後啟動就會要求輸入。

**有人作弊怎麼辦？** 成績由學生的瀏覽器回報，懂程式的人理論上可以偽造。
系統會把「45 秒內就跑完七站」的人標上「⚠ 太快」，老師可以請他再玩一次或不計入。
這個工具是課堂趣味用，不適合當正式成績。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `server.js` | 伺服器（沒有任何外部相依，只用 Node.js 內建功能） |
| `codespace-start.sh` | 在 GitHub Codespaces 內啟動伺服器 |
| `public/host.html` | 老師頁面 |
| `public/index.html` | 學生頁面（就是遊戲本體，加上加入房間／倒數／結算功能） |
| `public/three.min.js`、`public/qrcode.js` | 3D 與 QR code 程式庫（MIT 授權，見 `THIRD_PARTY_LICENSES.txt`） |

遊戲中的機台、數字與流程都是教學用的虛構簡化設定。背景音樂與音效皆由程式即時合成，沒有使用任何外部音檔。
